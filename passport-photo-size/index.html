Passport Photo Size for an Online Application

Photo mode starts at 50 KB, a practical middle size when you still need to type the form’s own limit.

Read the form, then set the ceiling

Online passport, visa, and identity uploads do not share one file size. One site asks for a small JPEG, another allows a larger one, and some also ask for pixel dimensions or a plain background. This page does not invent a worldwide rule. It opens the compressor so you can meet the number printed on the application you are filling.

Fifty kilobytes is already selected only as a starting point. Replace it with the maximum on the form before you press Compress. If that form also states width and height, enter both under More options. Leaving them blank keeps the shape of the photo you uploaded and only controls the file size.

The JPEG is built in the browser. Location and camera data from the original are not carried into the download, and the file name matches the size shown on screen. Check the likeness before you upload: a limit that is very small will look softer, which you can compare with the slider.

A signature, when the same form asks for one, is a different image. Use signature resize and the limit printed next to the signature, which is often not the portrait’s number. Exact ceilings of 20 KB and 100 KB are separate pages if the form names those.

Questions

Is 50 KB the official passport size?

No. Fifty is only the number this page starts with. Type the maximum written on the application.

Will this crop the photo to a passport shape?

Only if you enter both a width and a height. Otherwise the original proportions stay, and the tool limits the kilobytes.

Does the tool submit the application?

No. It only prepares the JPEG on this device. You still upload that file on the agency’s own site.
